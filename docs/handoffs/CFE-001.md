## Decisions and why

- **Mirror `packing-list-react`'s stack and layout.** Checked its current
  `package.json` / `vite.config.ts` / `tsconfig*.json` / `.oxlintrc.json`
  / `.prettierrc.json` / `src/` tree 2026-08-26. React 19, Vite (latest),
  **Tailwind v4** (`@tailwindcss/vite`, CSS-first `@theme` in
  `src/index.css`, no `tailwind.config.js`), Vitest + Testing Library +
  jsdom (`src/setupTests.ts` = `@testing-library/jest-dom/vitest` +
  `afterEach(cleanup)`), oxlint with `["react","typescript","oxc",
  "jsx-a11y"]` plugins, Prettier + `@ianvs/prettier-plugin-sort-imports`
  (copy the exact `importOrder`), husky + lint-staged. React Compiler on
  via `babel-plugin-react-compiler` + `@vitejs/plugin-react`. Layout:
  `src/{app,components/ui,features,lib,assets}` + `src/main.tsx`.
- **shadcn/ui, initialised now.** `stone` base colour (the design is warm
  cream/green, not cool gray), **no dark mode** (design has no dark
  variant — skip theme-switching infra entirely). Run `shadcn init`
  against shadcn's *current* official Vite + Tailwind-v4 guide (the steps
  drift — don't work from a pinned copy): it adds `components.json`, the
  `@/*` path alias (tsconfig `paths` + `vite.config` `resolve.alias`,
  needs `@types/node`), `src/lib/utils.ts` with `cn()`, and the
  `src/index.css` theme block using **shadcn's CSS-variable convention**
  (`--background`, `--foreground`, `--primary`, `--border`, `--ring`,
  …). Use that convention as-is — shadcn components reference
  `bg-background` / `text-foreground` / `border-border`; do **not**
  hand-roll `packing-list-react`'s `--color-bg` / `--color-heading`
  naming on top of it. Add only `button` + `sonner` components this
  ticket (CFE-002a/003 need them); everything else on demand.
- **Fonts: system-stack placeholder this ticket.** The design's serif
  treatment (Fraunces + Newsreader is the CFE-003 starting point) is a
  CFE-003 decision, made against the screenshots. CFE-001 sets
  `--font-display` / `--font-body` to a system stack so nothing depends
  on a missing face.
- **`VITE_API_URL`, no dev proxy.** `.env` + `.env.example` with
  `VITE_API_URL=http://localhost:8080` (matches `crockpot-go`'s default
  `PORT` and its `.env`'s `FRONTEND_URL=http://localhost:5173`).
  `vite.config.ts` gets **no** `server.proxy` — the client calls
  `crockpot-go` cross-origin directly, same as prod (see master-spec's
  auth-client architecture bullet).
- **TanStack Query provider** as a `src/lib/tanstack/` module
  (`queryClient.ts` + a provider component), mounted in `src/main.tsx`
  around `<App/>`, matching `packing-list-react/src/main.tsx` +
  `src/lib/Tanstack/`.
- **Vercel deferred.** No deployed `crockpot-go` to point `VITE_API_URL`
  at; prod needs its own CORS origin + `SameSite` story. Not in this
  ticket. No `vercel.json`, no project connection.
- **npm** (`package-lock.json`, like `packing-list-react`).

## Acceptance criteria

- [ ] `npm run dev` serves a page at `http://localhost:5173` with no
      console errors.
- [ ] `npm run build` (`tsc -b && vite build`) succeeds.
- [ ] `npm run lint` (oxlint) clean; `npm run format:check` clean.
- [ ] `npm test` (`vitest run`) executes and passes (a single trivial
      smoke test is fine; no real logic yet).
- [ ] `git commit` triggers husky → lint-staged (prettier + `oxlint
      --fix` on staged `*.{ts,tsx}`) with no errors.
- [ ] `src/` layout: `app/` (`App.tsx`, `AppRoutes.tsx` shell —
      `BrowserRouter` with at least a `/` route), `components/ui/`
      (shadcn `button`, `sonner`), `features/`, `lib/` (`api/`,
      `tanstack/`, `utils.ts`), `assets/`.
- [ ] `@/` alias resolves in both `tsc` and `vite` (a
      `import { cn } from "@/lib/utils"` compiles and runs).
- [ ] `components.json` present; `src/index.css` uses shadcn's CSS-var
      theme convention with `stone` base, no `.dark` block wired to a
      toggle.
- [ ] TanStack Query provider wraps `<App/>` in `src/main.tsx`.
- [ ] `.env.example` committed with `VITE_API_URL=http://localhost:8080`;
      `.env` gitignored; `vite.config.ts` has no `server.proxy`.
- [ ] `<Toaster/>` from `sonner` mounted once at app root (used by
      CFE-002a).

   `package.json` deps/versions/scripts with
   `packing-list-react/package.json` (dev/build/test/lint/format/preview/

   `@import "tailwindcss"` in `src/index.css`. (Ref:
   `packing-list-react/vite.config.ts`, `src/index.css:1`.)

   `@vitejs/plugin-react` babel option. (Ref:

   `.oxlintrc.json`, `.prettierrc.json`, `.prettierignore`,
