# CFE-061 — Landing page pre-launch tidy-up (Epic 2: Recipe Browsing)

Founder-raised after the pre-MVP bug run (2026-10-09). Undoes the
placeholder parts of `CFE-003`'s landing page that would read as unfinished
at launch. AI-driven. Agreed in conversation 2026-10-09; no separate grill,
since every open choice was settled there.

## Current state (read 2026-10-09)

- `Hero.tsx:14-18`: a hardcoded "189 recipes · free forever tier · no card"
  pill above the headline. `HowItWorks.tsx:17` repeats "Browse 189 recipes".
  The migrated catalogue has 213, so the number was already wrong.
- `RecipeCardPlaceholder`: grey photo box and "Recipe name" caption, three in
  the hero and two beside "Pick a plan", shown at `lg` and up only.
- `PlannerTease.tsx`: "Optional" badge, present-tense copy ("Switch the
  Planner on…"), and a "See the planner" button scrolling to `#pricing`. The
  planner (`CFE-012`) is post-launch.
- `LandingFooter.tsx`: Recipes and Pricing links, plus inert "Privacy" and
  "Contact" text. No privacy page exists.
- No public endpoint returns random or featured recipes; the landing page
  makes no API calls.

## Decisions

1. **Remove the pill** and change step 1 to "Browse the recipes and…" — no
   recipe count anywhere on the page.
2. **Showcase cards come from a hardcoded pool** of nine recipes (name, time,
   serves, Cloudinary URL), chosen for photo quality. Each page load picks
   five different ones: three for the hero, two for pricing. No API call.
   The frame and 4:3 photo box are fixed size and the title is one line,
   truncated, so the layout can't move.
3. **Cards aren't links.** Linking means hardcoding database IDs that break if
   a recipe is deleted.
4. **Planner tease reads as coming soon:** "Coming soon" badge, future-tense
   copy, and the "See the planner" button removed.
5. **A real `/privacy` page**, drafted by Claude from what `crockpot-go`
   actually stores, reviewed by the founder. Needed for UK GDPR and Google's
   OAuth consent screen. Only cookie is the strictly necessary refresh
   cookie, so no cookie banner.
6. **Footer:** logo, Recipes, Privacy, Contact (`mailto:`). Pricing dropped;
   the header already links to it.
